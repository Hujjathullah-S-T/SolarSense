# API documentation

FastAPI's interactive OpenAPI page is served at `/docs`. See the root README API overview. `GET /api/locations/search?q={city}` returns geocoded city, administrative region, country, internal coordinates, and timezone. Save a selected geocoder result using `PUT /api/installation` with its `location_id` and city. The backend resolves coordinates from Open-Meteo; clients do not provide coordinates. `POST /api/production/manual` accepts `{ "timestamp": "2026-11-15T10:30:00+05:30", "actual_kwh": 1.42, "interval_minutes": 60 }`; expected interval energy and classification are calculated from timestamp-aligned Open-Meteo weather when available. Pending readings can be retried with `POST /api/observations/{id}/analyze`. `DELETE /api/observations` deletes all stored CSV, manual, and simulated production observations so the derived diagnosis restarts empty; trained model artifacts are separate and are not removed. JSON errors include a descriptive `detail` field. CSV uploads have a 10 MB maximum.
